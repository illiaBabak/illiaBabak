# Setup

1. Open the GitHub profile repository named exactly `illiaBabak/illiaBabak`.
2. Copy `README.md` and the complete `assets/` directory to the repository root.
3. Commit and push both together.

The technology icons are stored locally in the repository, so the stack does
not depend on third-party icon CDNs. The two GitHub activity cards remain live
and are intentionally loaded from their statistics services.

To regenerate the SVG set, run `node generate-assets.mjs` from the directory
that contains this package.
